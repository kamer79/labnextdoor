# Lab Next Door Website — Version History

## v0.2.1 — Approved Logo Presentation & Living Circuit Background — 2026-09-18
- Preserved the approved LND artwork.
- Removed the circular hero presentation treatment and restored the artwork as supplied.
- Improved hero artwork spacing to keep the approved logo clear and unclipped across desktop and mobile.
- Expanded the circuit field with a denser, structured grid of dim blue PCB-like traces and node points.
- Changed the active pulse to blueish-white and kept the LND palette without introducing green.
- Animated the pulse along the actual circuit path geometry with automatic sequential activation.
- Retained click/tap activation for manual trace selection.
- Added reduced-motion handling for users who prefer less animation.

## v0.2.0 — Organized static-site structure — 2026-09-18
- Kept the working root `index.html` and preserved GitHub Pages compatibility.
- Added organized CSS, JavaScript, data, project, download and documentation directories.
- Added responsive navigation, project landing pages and reusable content catalogs.

## v0.1.1 — GitHub Pages Deployment Structure Fix — 2026-09-18
- Repackaged the original v0.1.0 website with the correct GitHub Pages directory structure at the ZIP root.
- Preserved the existing HTML, CSS, JavaScript, branding assets, content folders, and locked LND color identity.
- No visual/design feature changes were made.
- This package is intended to prevent relative-path failures caused by flattening `css/`, `js/`, or `assets/` files during GitHub upload.

## v0.1.0 — Initial Website Foundation — 2026-09-18
- Created first GitHub Pages-ready static website.
- Applied locked LND identity palette: #0D1B2A, #1C3F6E, #378ADD, #F5800A, #6B7280, #F2F4F7.
- No green used.
- Added 3D LND logo assets from the marketing kit.
- Added responsive Home, Projects, Lab Notes, YouTube, Downloads and About sections.
- Added interactive circuit-field background: dim traces, click-to-activate path, travelling pulse and fade-out.
- Added mobile navigation.
- Added basic SEO metadata, favicon, sitemap/robots placeholders to be completed when the final domain is known.

## Versioning rule
- MAJOR: structural/design-breaking changes.
- MINOR: new features/sections that remain compatible.
- PATCH: fixes, copy changes, small visual/technical corrections.
